# Diagram untuk U5 — Kerangka MID APL

Semua diagram ini adalah **CONTOH DESAIN USULAN**, bukan diagram sistem UMI yang sudah diterapkan. Diskusikan dengan anggota U3, U4, U5, U6, dan U7 sebelum memakai sebagai laporan akhir.

- `diagram-konteks.png` — gambar diagram konteks.
- `diagram-konteks.drawio` — versi edit diagram konteks.
- `diagram-arsitektur.png` — gambar diagram arsitektur yang menunjukkan **contoh** layered dan publish–subscribe.
- `diagram-arsitektur.drawio` — versi edit.
- `diagram-uml-activity.png` — gambar UML activity tentang proses peminjaman dan pembaruan status.
- `diagram-uml-activity.drawio` — versi edit.

Edit `.drawio` melalui https://app.diagrams.net/ (pilih Device → Open Existing Diagram atau File → Open From → Device). Setelah revisi, export PNG yang baru agar isi gambar sama dengan sumber editnya.

**Konsistensi:** Pertahankan nama komponen yang sama di U3–U7. Jelaskan mekanisme sinkronisasi dan potensi keterlambatan jika memakai event. Jangan mengeklaim bahwa fitur usulan telah tersedia di perpustakaan UMI.
