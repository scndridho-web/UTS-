## Pembagian file kerja
- `U1-konteks-ASR.md`: Konteks, bukti masalah, 4 stakeholder, 3 ASR, 3 karakteristik pendorong.
- `U2-skenario-atribut-kualitas.md`: 3 skenario, **masing-masing 6 komponen** dan ukuran respons numerik.
- `U3-taktik.md`: Minimal 1 taktik per skenario, cara kerja, dan konsekuensi/biaya.
- `U4-pola-arsitektur.md`: Minimal 2 pola dari kategori berbeda, analisis pro-kontra, dan perbedaan gaya/pola.
- `U5-desain-dan-diagram.md`: 3 diagram berketerangan dan 3 prinsip desain.
- `U6-evaluasi.md`: Pohon utilitas mini, trade-off berbobot dua alternatif, analisis ala ATAM, dan jawaban masalah utama.
- `U7-ADR.md`: 2 ADR **baru** (Title, Status, Context, Decision, Consequences).
- `diagram/`: PNG dan file `.drawio` yang **bisa diedit**. Semua diagram masih CONTOH USULAN, bukan sistem UMI yang sudah diterapkan.
